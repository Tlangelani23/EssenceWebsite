# Essence – Online Perfume Store Platform

## 1. Project Name

**Essence** – Online Perfume Store Platform

## 2. Target Client / Audience

The system is designed for:

- **Customers**: Individuals interested in purchasing perfumes or exploring customized fragrances online. This includes both local customers in Cape Town and a broader online audience.
- **Store Owner / Vendor**: The business owner who manages perfume listings, updates product details, and responds to customer inquiries.
- **System Administrator**: Responsible for maintaining the system, ensuring smooth operation, and managing backend processes.

## 3. Background

*“Essence of the Middle East”* is currently a physical perfume store located in Cape Town. It offers both branded fragrances and customized scents tailored to customer preferences.

However, the business faces several limitations:

- Customers must physically visit the store to browse products.
- No online presence exists to showcase available perfumes.
- Limited reach to customers who prefer online shopping.
- Inability to scale and compete in a digital marketplace.

With the rapid shift toward e-commerce, the absence of an online platform restricts business growth and customer accessibility.

## 4. Purpose of the Project

The purpose of this project is to develop a web-based e-commerce platform that:

- Allows users to browse perfumes online
- Displays product details (name, price, description, images)
- Enables users to add/remove items from a cart
- Provides information about custom perfume creation
- Allows users to contact the store or request personalized scents
- Improves accessibility and convenience
- Expands the business reach beyond a physical location

Ultimately, the system aims to digitize the store experience and improve customer engagement.

## 5. Tools Used to Develop the Project

### Frontend Technologies
- **HTML** – Structure and layout of the website
- **CSS / Bootstrap** – Styling and responsive design
- **JavaScript** – Interactivity (form validation, UI behavior)

### Backend Technologies
- **PHP** – Server-side logic, session management, database interaction

### Database
- **MySQL** – Storage of users, products, orders, and other data

### Development Environment
- **Laragon** – Local server for development and testing
- **Visual Studio Code (VS Code)** – Code editor and development IDE

## 6. Definition of Done (DoD)

The project will be considered complete when:

- **All core features are implemented**, including:
  - Product catalog
  - Product detail pages
  - Cart functionality
  - Contact/inquiry system

- **The system:**
  - Displays all products with images, descriptions, and prices
  - Allows users to add and remove items from the cart
  - Provides a responsive design across devices
  - Includes working navigation (Home, Products, About, Contact, Cart)

- **Backend functionality:**
  - Successfully connects to the MySQL database
  - Retrieves and displays data dynamically using PHP

- **The system has undergone:**
  - Testing (unit and system testing)
  - Bug fixing and UI refinement

- **Documentation is completed and the project is:**
  - Ready for presentation and submission

## 7. Look and Feel of the Project

The website will have a modern, clean, and user-friendly interface with the following characteristics:

### Design Style
- Elegant and minimalistic (to reflect luxury perfumes)
- Professional and visually appealing
- Consistent color scheme and typography

### User Interface Elements
- Navigation bar for easy movement between pages
- Product cards displaying images, names, and prices
- Search and filter options (e.g., floral, woody, etc.)
- Responsive layout (mobile, tablet, desktop compatibility)

### User Experience (UX)
- Simple and intuitive navigation
- Fast-loading pages
- Clear product information
- Easy-to-use cart system

### Pages Included
- Home Page
- Products Page
- Product Details Page
- About Page
- Contact Page
- Cart Page
